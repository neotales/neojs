# VaelJS Documentation

The VaelJS documentation site, guides, CLI references, architecture specs, and blog live at:

- **Website:** <https://vaeljs.com>
- **Site repository:** <https://github.com/neotales/vaeljs-site>

## Source of Truth in This Repository

- **TypeScript API declarations & `@since` metadata:** [`vaeljs-dts/types/`](../vaeljs-dts/types/) (`vjs types` / `vjs-lite types`) remain the canonical API surface and `@since` version source of truth in `neotales/vaeljs`.
- **Crate documentation:** Each workspace crate documents its Rust embedding surface in its own `README.md` and rustdoc comments.
